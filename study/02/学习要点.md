# study/02 学习要点

这套页面把 `design/` 里的 10 个设计稿重写成了更适合学习 HTML/CSS 的版本：保留了原来的视觉效果，但把代码展开、加上注释、补上了语义标签。

建议一边打开页面，一边对照本文件看源码。

## 一、怎么用这套页面

### 打开方式

直接双击 `index.html`，或在 `study/02/` 下启动本地服务器：

```bash
cd study/02
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/`。

### 推荐学习顺序

1. `index.html`（首页）：先认识整体结构和最常见的 Flex/Grid。
2. `login.html`、`register.html`、`forgot-password.html`：表单和居中布局。
3. `app-center.html`：卡片网格和修饰类。
4. `exam-lib.html`：两栏布局和 sticky。
5. `exam-upload.html`：表单细节。
6. `community.html`：信息流卡片。
7. `profile.html`：多面板页面。
8. `admin-console.html`：后台布局和表格。

### 读一个页面的四步

1. 先看 `<body>`：用注释找出页面分成哪几个区块。
2. 再看每个区块用了哪些标签：`header`、`nav`、`main`、`section`、`article`、`aside`、`footer`。
3. 然后在 `<style>` 里找对应 class：先看 `display`、`position`、`width`，再看颜色和间距。
4. 最后改一个值，刷新页面观察变化。

## 三、先掌握 6 个公共概念

### 1. 设计令牌（CSS 变量）

文件：`assets/tokens.css`

```css
:root {
  --brand: #2F6BFF;
  --ink: #1C1F26;
  --r-md: 12px;
}
```

页面里这样使用：

```css
body {
  color: var(--ink);
}
```

变量定义在 `:root`，所有后代元素都能继承。把 `--brand` 改成另一个颜色，所有用到它的按钮、链接、标签会一起变化。

**注意**：设计令牌和 GitHub 的 access token 没有关系，这里指“设计变量”。

### 2. 盒模型

一个元素实际占用的宽度 =

```
content 宽度 + 左右 padding + 左右 border + 左右 margin
```

本套页面大多沿用设计稿的默认 `content-box`。例如首页搜索框：

```css
.search input {
  width: 100%;
  padding: 0 16px 0 40px;
  border: 1px solid var(--line);
}
```

它的实际宽度会大于父容器。个人中心、登录、注册等表单里则显式写了 `box-sizing: border-box`，让 `width:100%` 包含 padding 和 border。

**对比这两个写法，是理解盒模型最快的方式。**

### 3. Flexbox：一维排列

```css
.nav {
  display: flex;
  align-items: center;   /* 交叉轴：垂直居中 */
  gap: 26px;             /* 子元素间距 */
}
```

常用属性：

| 属性 | 作用 |
|---|---|
| `display:flex` | 变成弹性容器 |
| `align-items` | 交叉轴对齐 |
| `justify-content` | 主轴对齐 |
| `gap` | 子元素间距 |
| `flex:1` | 占满剩余空间 |
| `flex:0 0 40px` | 不放大、不缩小、固定 40px |
| `margin-left:auto` | 把元素推到最右 |

判断场景：**一行或一列内的排列**，用 Flex。

### 4. Grid：行列网格

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}
```

常见写法：

- 三栏卡片：`repeat(3, 1fr)`
- 两栏布局：`220px 1fr`（左固定、右自适应）
- 四列指标：`repeat(4, 1fr)`
- 两列表单：`1fr 1fr`

判断场景：**需要同时控制行和列**，用 Grid。

### 5. 定位与层叠

| 值 | 用途 | 本套页面中的例子 |
|---|---|---|
| `position: relative` | 给子元素提供定位参照 | `.school`、`.search` |
| `position: absolute` | 相对最近的 relative 祖先定位 | `.search .mag`、`.school .menu` |
| `position: sticky` | 滚动时吸附 | 首页导航、真题库侧栏、社区侧栏 |
| `z-index` | 控制谁在上面 | 导航 `z-index:10`，下拉菜单 `z-index:50` |

### 6. 选择器与优先级

```css
.nav a        /* 一个 class + 一个标签 */
.nav a.on     /* 两个 class + 一个标签，更具体 */
.cat.on       /* 两个 class */
```

优先级从高到低大致是：行内样式 > id > class/属性/伪类 > 标签。

本套页面里有两个值得注意的地方：

- 首页 logo 从 `div` 改成 `a` 后，用 `.nav .logo` 提高优先级，避免被 `.nav a` 的字号和颜色覆盖。
- `.btn.ghost` 同时写两个 class，表示“按钮 + 次要变体”。

## 1. 首页 `index.html`

**对应设计稿**：`design/P1-home.html`

### 这页在练什么

用一个页面练完最常见的布局：顶部 Flex 导航、三栏 Grid、卡片、列表、页脚。

### HTML 结构要点

- `header > nav`：顶部导航。
- `main.wrap`：页面主体。
- `section.hero`：主视觉区。
- `section.grid`：三栏容器，里面三个 `article.panel`。
- `aside.notice`：通知条。
- `footer`：页脚。

导航里的 logo 是一个链接：

```html
<a class="logo" href="index.html">
  <span class="mark" aria-hidden="true">校</span>
  校内网 2.0
</a>
```

`aria-hidden="true"` 表示装饰性字符不需要被读屏软件朗读。

### CSS 要点

- `.nav`：`display:flex` + `align-items:center` + `gap:26px`。
- `.search`：`flex:1` 占剩余空间，`margin-left:auto` 把它推到右侧。
- `.school`：`position:relative`；`.school .menu` 用 `position:absolute` 挂在下拉按钮下方。
- `.hero`：`linear-gradient` 渐变背景。
- `.hero .chat`：输入框 `flex:1`，按钮固定宽度。
- `.grid`：`grid-template-columns:repeat(3,1fr)`。
- `.panel`：卡片底色、边框、圆角、内边距。
- `.panel .more`：设计稿用 `float:right` + 负 margin 实现右上角链接，能用但不推荐。
- `.exam:last-child`：结构伪类，去掉最后一项的下边框。

### 建议阅读顺序

1. `body` 的注释，看页面分几块。
2. 导航 HTML → `.nav`、`.search`、`.school` 的 CSS。
3. hero HTML → `.hero`、`.chat`、`.q` 的 CSS。
4. 三栏 HTML → `.grid`、`.panel`、`.path`、`.exam`、`.post` 的 CSS。
5. 页脚。

### 动手练习

1. 打开 `assets/tokens.css`，把 `--brand` 改成 `#E24B4A`，刷新页面，观察哪些地方变色。
2. 把 `.grid` 的 `repeat(3, 1fr)` 改成 `repeat(2, 1fr)`，看三栏如何变成两栏。
3. 把 `.panel .more` 的 float 写法去掉，改成用 Flex 让标题和“全部 ›”左右对齐。
4. 给导航加一个 `position` 变化：把 `sticky` 改成 `static`，滚动页面观察区别。

卡片网格、分类标签、同一个组件用不同修饰类表示状态。

- `header.pagehead`：页面标题 + 别名。

## 3. 真题库 `exam-lib.html`

**对应设计稿**：`design/P4-exam-lib.html`

### 这页在练什么

固定宽度侧栏 + 自适应主内容的典型两栏布局，以及 sticky 侧栏。

### HTML 结构要点

- `aside.side`：学院/学期筛选。
- `main.main`：AI 问答 + 真题列表 + 分页。
- `a.upbtn`：外观像按钮，实际是链接，点击进入 `exam-upload.html`。
- `section.qa`：AI 问答卡片，内部用一个 `form.row` 装输入框和按钮。
- `section.list`：真题列表，每条是 `article.exam`。
- `nav.pager`：分页。

### CSS 要点

- `.wrap`：`display:grid; grid-template-columns:220px 1fr; gap:24px;`。
- `.side`：`position:sticky; top:80px;`，滚动时保持可见。
- `.upbtn`：因为元素是 `<a>` 而不是 `<button>`，要补 `display:flex`、`align-items:center`、`justify-content:center`、`text-decoration:none`。
- `.qa`：135° 渐变背景。
- `.qa .row`：Flex，`input` 用 `flex:1`。
- `.file`：`flex:0 0 40px`，固定宽度且不被压缩。
- `.exam .t`：`flex:1`，占满中间空间。
- `.qa2`：`white-space:nowrap`，防止“就这份提问”换行。
- `.pager span`：用 `min-width` + Flex 居中做方形页码。

### 建议阅读顺序

1. `.wrap` 的两栏 Grid。
2. `.side` 及其 sticky。
3. `.qa` 卡片和 `.row`。
4. `.exam` 行内部的 `file / t / qa2 / dl` 四个部分。
5. `.pager`。

### 动手练习

1. 把 `.wrap` 的 `220px` 改成 `280px`，观察主内容宽度变化。
2. 把 `.side` 的 `position:sticky` 删掉，滚动对比。
3. 把 `.qa2` 从 `<span>` 改成 `<button>`，需要补哪些重置样式？

## 4. 上传真题 `exam-upload.html`

**对应设计稿**：`design/P6-exam-upload.html`

### 这页在练什么

表单结构：`form`、`label`、`input`、`select`、隐藏的文件输入框、focus 状态。

### HTML 结构要点

- `form.panel`：整张表单卡片。
- `label for="file"` 关联隐藏的 `<input type="file" id="file" hidden>`。
- `label.drop`：点击整个虚线区域都会触发文件选择。
- `.frow`：两列表单行。
- `section.aibox`：AI 识别结果。
- `.kv`：键值行。
- `.actions`：取消 / 提交按钮。

### CSS 要点

- `.wrap`：`max-width:640px; margin:0 auto;`，表单页不需要满屏。
- `.field input, .field select`：统一 `width:100%; height:42px;`。
- `:focus` 伪类：输入时边框变主色。
- `.drop`：虚线边框 + 居中文字；因为元素是 `<label>`，要补 `display:block`。
- `.frow`：`display:grid; grid-template-columns:1fr 1fr;`。
- `.kv`：Flex，`.k` 用 `flex:0 0 90px` 固定标签宽度，`.v` 用 `flex:1`。
- `.actions .ghost` 和 `.actions .primary`：`flex:1` 与 `flex:2` 控制按钮宽度比例。

### 建议阅读顺序

1. `.wrap` 的宽度限制。
2. `<form>` 里从上到下的字段顺序。
3. 文件选择区的 label + hidden input。
4. `.field`、`.frow`、`.kv`。
5. `.actions` 的两个按钮。

### 动手练习

1. 给表单再加一个“备注”输入框。
2. 把 `.wrap` 的 `max-width` 改成 `800px`，观察表单宽度。
3. 把 `:focus` 的边框颜色改成 `var(--danger)`。
4. 把 `.frow` 改成单列，观察字段排列变化。

## 10. 后台工作台 `admin-console.html`

### 这页在练什么

### HTML 结构要点

- 表格使用完整语义结构：

```html
<table class="table">
  <thead>
    <tr><th>文件</th><th>AI 识别</th></tr>
  </thead>
  <tbody>
    <tr><td>...</td><td>...</td></tr>
  </tbody>
</table>
```

### CSS 要点

- `.top`：深色背景 + Flex 排列。
- `.wrap`：`grid-template-columns:190px 1fr;`。

## 六、与设计原稿的差异说明

这些是有意为之的改写，不是还原错误：

1. **导航统一**：`P4`、`P7` 原稿把学校选择器放在导航外，学习版统一移入导航，页面整体会比原稿上移一点。
2. **按钮语义**：学校选择、发帖、搜索等从 `div` 改为 `button`，并用 `border:none`、`font-family:inherit` 等重置保持外观。
3. **表单结构**：登录、注册、上传、个人中心等页面使用了真正的 `form`、`label for`、`id`，方便学习表单关联；页面没有后端，提交只会刷新当前页。
4. **链接目标**：`P11` 的管理员入口指向 `admin-console.html`；`P4` 的上传按钮指向 `exam-upload.html`。
5. **补充项**：所有页面加了 `viewport`、语义标签、分区注释；删除了行内 `style`。
6. **未做项**：没有 JavaScript、没有响应式断点、没有全局 `box-sizing` 重置，这些都留作练习。
