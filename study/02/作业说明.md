# study/02 动态页面作业说明

课程仓库 study/02 的学习版是纯 HTML/CSS（《学习要点.md》里把 JavaScript 列为"未做项，留作练习"）。
本次作业在保持原有视觉和结构不变的前提下，用原生 JavaScript 给 6 个页面补上了动态交互。
所有改动都用 `【作业新增】` / `【作业修改】` 注释在代码里标出。

## 运行方式

直接双击 `index.html` 即可（页面没有外部依赖）。
也可以在本目录起一个本地服务器，例如 `python -m http.server 8000`，再访问 `http://localhost:8000/`。

## 新增的动态交互

重点按要求做了**登录 → 后台**这条线的动态化，其他页面配了几个典型小交互：

| 页面 | 交互效果 | 主要知识点 |
|---|---|---|
| `login.html`（重点） | 空字段提交时红字提示缺哪项；填好后按钮变「登录中…」，800ms 后跳转 `admin-console.html` | `submit` 事件、`preventDefault`、`setTimeout`、`location.href` 页面跳转 |
| `admin-console.html`（重点） | 点「✓ 通过 / ✗ 驳回」删掉对应表格行，KPI「待审核真题」和左侧导航角标同步 -1；口令表单校验（新口令 ≥ 6 位，绿字/红字反馈） | 事件委托、`closest` 向上查找、`tr.remove()`、文本节点更新、`form.reset()` |
| `index.html` | 学校下拉菜单点击展开/收起，选择学校后更新按钮文字，点空白处收起 | `classList.toggle`、事件委托、`contains` 判断点击区域 |
| `app-center.html` | 搜索框实时过滤工具卡片（每输入一个字符立即生效） | `input` 事件、`textContent`、`style.display` 显隐 |
| `exam-lib.html` | 点「✨ 就这份提问」把科目名自动填进顶部 AI 问答框并平滑滚回顶部；分页页码点击切换选中 | `closest`、`focus()`、`scrollTo({behavior:'smooth'})` |
| `community.html` | 点赞点一次 +1 变色、再点还原；「最新 / 热门」标签切换选中态 | `classList.toggle` 的返回值、数字与字符串转换 |

## 没有动的部分

- `assets/tokens.css` 设计令牌、页面视觉、HTML 结构保持原样；
- 唯一的例外是首页学校菜单：原稿是"永远显示"的静态演示（源码注释也写了"真实项目需要 JS 控制"），改成默认隐藏、由 JS 控制；
- `register.html`、`forgot-password.html`、`exam-upload.html`、`profile.html` 四页未加交互，作为下一步练习。

## 一点说明

- 全部使用原生 JS（`var` + `function`），不依赖任何库，方便逐行阅读；
- 每段脚本都放在 `</body>` 之前：此时 HTML 已加载完，可以直接查询 DOM；
- 学习版没有后端，所有"提交/审核"都只改当前页面，刷新后恢复原样——真实项目里这些操作应先发请求给后端。
