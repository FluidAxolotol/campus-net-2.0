# 03 · 接口文档

Base URL：`/api`。所有请求同源，凭 Cookie 识别会话，不需要 CORS。

## 1. 约定

### 1.1 成功响应

单个对象：

```json
{ "data": { "user": { "...": "..." } } }
```

列表：

```json
{
  "data": [ ],
  "meta": { "page": 1, "pageSize": 10, "total": 42, "totalPages": 5 }
}
```

### 1.2 失败响应

```json
{
  "error": {
    "code": "USER_PENDING",
    "message": "账号正在等待管理员审核，请耐心等待",
    "details": { "field": "可选字段级错误" },
    "requestId": "请求 id，用于查日志"
  }
}
```

### 1.3 CSRF

- 除 `GET/HEAD/OPTIONS` 外的所有请求必须带：
  - Cookie `campus_csrf`（由 `GET /api/csrf` 下发）；
  - 请求头 `X-CSRF-Token`，值与 Cookie 相同。
- 返回 403 `CSRF_INVALID` 时，前端清缓存重取一次。

### 1.4 会话 Cookie

| Cookie | 角色 |
|---|---|
| `campus_sid` | 学生 |
| `campus_admin_sid` | 管理员 |

均为 HttpOnly、SameSite=Lax；生产 HTTPS 下加 Secure。

### 1.5 学校参数

- 学生登录后，学校来自服务端会话，URL 中的 `schoolId` 会被忽略；
- 游客浏览公开列表时可带 `?schoolId=1`；
- 管理员学校来自管理员会话的 `currentSchoolId`，通过切换接口修改。

### 1.6 分页

`?page=1&pageSize=10`，`pageSize` 最大 50。

## 2. 基础接口

| 方法 | 路径 | 登录 | 说明 |
|---|---|---|---|
| GET | `/api/health` | 否 | 健康检查，`SELECT 1`，返回 `{data:{status:'ok',db:'ok'}}` |
| GET | `/api/csrf` | 否 | 下发/复用 CSRF 令牌，返回 `{data:{token}}` |
| GET | `/api/schools` | 否 | 可选学校列表，只返回 active |

## 3. 学生认证

### POST `/api/auth/register`

请求：

```json
{
  "schoolId": 1,
  "studentNo": "23332001",
  "email": "newbie@mail.sysu.edu.cn",
  "displayName": "新同学",
  "password": "Newbie@2026",
  "degree": "本科",
  "enrollYear": 2025,
  "college": "计算机学院"
}
```

成功 201：

```json
{
  "data": {
    "id": 5,
    "status": "pending",
    "schoolName": "中山大学",
    "email": "newbie@mail.sysu.edu.cn",
    "message": "注册申请已提交，管理员审核通过后即可登录"
  }
}
```

错误：422 字段校验 / `EMAIL_DOMAIN_INVALID`；409 `EMAIL_EXISTS`、`STUDENT_NO_EXISTS`；403 `SCHOOL_DISABLED`。

### POST `/api/auth/login`

```json
{ "account": "alice@mail.sysu.edu.cn", "password": "Student@2026", "rememberMe": true }
```

成功 200：`{data:{user, rememberMe}}`，同时 `Set-Cookie: campus_sid`。

错误：

| HTTP | code | 说明 |
|---|---|---|
| 401 | `AUTH_INVALID` | 账号或密码错误（统一文案） |
| 403 | `USER_PENDING` | 待审核 |
| 403 | `USER_REJECTED` | 被驳回，`details.reason` |
| 403 | `USER_DISABLED` | 被停用 |
| 403 | `SCHOOL_DISABLED` | 学校停用 |
| 409 | `AMBIGUOUS_ACCOUNT` | 学号跨校重复，改用邮箱 |
| 423 | `USER_LOCKED` | 5 次密码错误，锁 15 分钟 |

### POST `/api/auth/logout`

清会话与 Cookie，返回 204。

### GET `/api/auth/me`

需要学生登录。返回：

```json
{
  "data": {
    "user": {
      "id": 1, "schoolId": 1, "studentNo": "23331001",
      "email": "alice@mail.sysu.edu.cn", "displayName": "小张",
      "degree": "本科", "enrollYear": 2023, "college": "计算机学院",
      "bio": null, "status": "active",
      "school": { "id": 1, "name": "中山大学", "code": "sysu", "emailDomain": "mail.sysu.edu.cn" }
    },
    "stats": { "uploads": 2, "posts": 2, "likesReceived": 1 }
  }
}
```

### POST `/api/auth/password-reset-request`

```json
{ "schoolId": 1, "account": "bob@mail.sysu.edu.cn", "note": "换了手机号" }
```

为避免枚举，无论账号是否存在都返回成功提示。

## 4. 首页 / 应用

### GET `/api/home`

- 登录：无需参数，学校来自会话；
- 游客：必须带 `schoolId`。

返回：

```json
{
  "data": {
    "school": { "id": 1, "name": "中山大学", "code": "sysu" },
    "stats": { "apps": 5, "exams": 4, "posts": 3 },
    "apps": [],
    "exams": [],
    "posts": []
  }
}
```

每块最多 3–4 条，已按状态过滤。

### GET `/api/apps?category=&q=&page=&pageSize=`

游客带 `schoolId`，登录用户不需要。返回 active 应用列表。

### GET `/api/apps/:id`

返回 `{data:{app, school}}`，并让 `views + 1`。跨校/下架返回 404。

### POST `/api/apps/:id/corrections`

学生登录。`{content:"第 2 步菜单名变了"}`，返回 201。限流 10 次/小时。

## 5. 真题

### GET `/api/exams?college=&semester=&q=&page=&pageSize=`

游客带 `schoolId`。只返回 `approved` 且本校的真题。

```json
{
  "data": [
    {
      "id": 1, "title": "高等数学 A（一）· 2025 秋期末",
      "subject": "高等数学 A（一）", "college": "数学学院",
      "semester": "2025 秋", "examType": "期末", "hasAnswer": true,
      "downloadCount": 518, "reviewNote": "",
      "uploader": { "id": 1, "displayName": "小张" },
      "file": { "originalName": "...", "fileType": "PDF", "sizeBytes": 865 },
      "downloadUrl": "/api/exams/1/download"
    }
  ],
  "meta": { "page": 1, "pageSize": 10, "total": 4, "totalPages": 1 }
}
```

### GET `/api/exams/:id`

学生/游客均可（游客带 `schoolId`），只返回公开或上传者本人的真题；跨校 404。

### POST `/api/exams`（multipart/form-data）

需要学生登录。字段：

| 字段 | 必填 | 规则 |
|---|---|---|
| file | 是 | PDF/JPG/PNG，≤20MB，魔数校验 |
| title | 是 | 4–160 字 |
| subject | 是 | ≤80 字 |
| college | 是 | ≤80 字 |
| semester | 是 | ≤20 字 |
| examType | 否 | 默认期末 |
| hasAnswer | 否 | `true` / `false` |

成功 201：`{data:{id,status:'pending',message}}`。
错误：413 `FILE_TOO_LARGE`；422 `FILE_TYPE_INVALID` / `VALIDATION_FAILED`；401 未登录。

### GET `/api/exams/:id/download`

需要学生登录。权限：上传者本人可下载任意状态，其他人仅 `approved`。跨校 404。
本地返回文件流；生产返回 `X-Accel-Redirect`，由 Nginx 发文件。

## 6. 真题问答（演示）

### GET `/api/exams/:id/questions`

需要学生登录。返回真题信息 + 历史问答。

### POST `/api/exams/:id/questions`

```json
{ "question": "最后一题考什么？" }
```

成功 201：`{data:{thread:{id,question,answer,createdAt,user}}}`。答案明确标“演示版问答”。

跨校 404；游客 401；限流 30 次/小时。

## 7. 社区

### GET `/api/boards`

游客带 `schoolId`；返回本校版块与帖子数。

### GET `/api/posts?boardId=&sort=latest|hot&q=&page=&pageSize=`

游客带 `schoolId`。返回已发布帖子 + 作者/版块 + `likedByMe`。

### POST `/api/posts`

学生登录：

```json
{ "boardId": 1, "title": "9 成新台灯", "content": "东校区自提" }
```

成功 201。限流 10 次/小时。

### POST `/api/posts/:id/like`

学生登录。切换点赞状态，返回：

```json
{ "data": { "liked": true, "likeCount": 4 } }
```

事务内锁帖子行，防止并发计数错乱。跨校 404。

## 8. 个人中心

### GET `/api/profile`

学生登录。返回 `user / stats / exams / posts`。

### PATCH `/api/profile`

```json
{ "displayName": "小张", "college": "计算机学院", "bio": "帮一届，是一届" }
```

只允许改昵称、学院、简介。

### POST `/api/profile/password`

```json
{ "currentPassword": "Student@2026", "newPassword": "NewPass@2026" }
```

## 9. 管理员认证

### POST `/api/admin/auth/login`

```json
{ "schoolId": 1, "username": "campusadmin", "password": "Admin@2026" }
```

成功 200：`{data:{stage,admin,school}}`，并设置 `campus_admin_sid`。

`stage`：

- `setup_required`：首次登录/恢复后；
- `totp_required`：日常登录，还需要动态码。

### GET `/api/admin/auth/setup`

只有 `setup_required` 阶段可访问。返回：

```json
{
  "data": {
    "secret": "BASE32...",
    "otpauthUrl": "otpauth://totp/...",
    "qrDataUrl": "data:image/png;base64,...",
    "account": "campusadmin",
    "issuer": "校内网2.0",
    "hint": "打开微信「腾讯身份验证器」小程序 → 扫一扫 → 添加账户",
    "school": { "id": 1, "name": "中山大学" }
  }
}
```

### POST `/api/admin/auth/setup`

```json
{ "newPassword": "Admin@2027", "code": "123456" }
```

成功：`stage=active`，返回一次性 `recoveryCodes`（8 个）。恢复码只显示一次。

### POST `/api/admin/auth/verify`

```json
{ "code": "123456" }
```

只有 `totp_required` 阶段可访问。成功进入 `active`。错误：

- 401 `TOTP_INVALID`：码错/过期；
- 401 `TOTP_REPLAY`：同码已用过；
- 403 `ADMIN_SETUP_REQUIRED`：未完成绑定。

### POST `/api/admin/auth/recovery`

```json
{ "code": "XXXX-XXXX-XXXX-XXXX" }
```

使用一次性恢复码，作废旧 TOTP，返回 `stage=setup_required`。

### GET `/api/admin/auth/me`

返回 `stage / admin / school`。未登录 401。

### POST `/api/admin/auth/logout`

清管理员会话与 Cookie，204。

### POST `/api/admin/auth/switch-school`

```json
{ "schoolId": 2 }
```

要求 `stage=active`；更新会话 `currentSchoolId` 并写审计。

### POST `/api/admin/auth/password`

需要 `active`：

```json
{ "currentPassword": "...", "newPassword": "...", "code": "123456" }
```

需要当前密码 + 动态码；其他设备管理员会话失效。

## 10. 管理后台业务

以下全部要求 `stage=active` 且当前学校有效；学校来自会话，不来自 URL。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/admin/overview` | 当前学校 KPI |
| GET | `/api/admin/registrations?status=pending` | 注册审核列表 |
| POST | `/api/admin/registrations/:id/approve` | 通过注册 |
| POST | `/api/admin/registrations/:id/reject` | 驳回，body `{reason}` |
| POST | `/api/admin/users/:id/status` | `{status:'active'|'disabled'}`，停用即删会话 |
| GET | `/api/admin/exams?status=pending` | 真题审核列表 |
| POST | `/api/admin/exams/:id/review` | `{action:'approve'|'reject', note}` |
| GET | `/api/admin/posts?status=published` | 帖子管理 |
| POST | `/api/admin/posts/:id/status` | `published/hidden/deleted` |
| GET | `/api/admin/corrections?status=open` | 纠错列表 |
| POST | `/api/admin/corrections/:id/status` | `resolved/ignored` + note |
| GET | `/api/admin/reset-requests?status=open` | 找回密码申请 |
| POST | `/api/admin/reset-requests/:id/handle` | `{action:'reset'|'ignore'}`；reset 返回一次性临时密码 |
| GET | `/api/admin/apps` | 应用列表（含下架） |
| POST | `/api/admin/apps/:id/status` | `active/hidden` |
| GET | `/api/admin/audit-logs` | 审计日志 |

所有写操作都写审计（`audit_logs`），不记录密码/动态码/恢复码。

## 11. curl 示例：完整登录

```bash
# 1. 拿 CSRF Cookie + token
curl -c jar.txt http://127.0.0.1:3100/api/csrf

# 2. 用同一个 cookie jar 登录
curl -b jar.txt -c jar.txt \
  -H 'Content-Type: application/json' \
  -H 'X-CSRF-Token: <上一步返回的 token>' \
  -d '{"account":"alice@mail.sysu.edu.cn","password":"Student@2026","rememberMe":true}' \
  http://127.0.0.1:3100/api/auth/login

# 3. 带着会话 Cookie 请求 /me
curl -b jar.txt http://127.0.0.1:3100/api/auth/me
```

## 12. 状态码速查

| 码 | 含义 |
|---|---|
| 200 | 成功 |
| 201 | 创建成功（注册、上传、发帖、问答） |
| 204 | 成功但无响应体（退出） |
| 400 | JSON 格式错误 |
| 401 | 未登录 / 密码错 / 动态码错 |
| 403 | CSRF / 状态不允许 / 阶段不对 |
| 404 | 不存在或跨校 |
| 409 | 唯一冲突 / 重复审核 / 学号歧义 |
| 413 | 文件过大 |
| 422 | 字段校验失败 / 文件类型错 |
| 423 | 密码失败锁定 |
| 429 | 限流 |
| 500 | 服务端异常（看 requestId 与日志） |
